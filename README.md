# Сайт ЮнАтом

Файлы для публикации на GitHub Pages.

- `index.html` — сайт целиком
- `.nojekyll` — отключает обработку Jekyll

## Шаги

### 1. Загрузить файлы на GitHub
1. Зайдите на github.com и войдите в аккаунт (или зарегистрируйтесь).
2. Нажмите **New repository**. Название, например, `unatom`. Выберите **Public** и нажмите **Create repository**.
3. Нажмите **uploading an existing file** и перетащите файлы из этой папки: `index.html`, `.nojekyll`, `README.md`. Нажмите **Commit changes**.

### 2. Включить GitHub Pages
1. Откройте репозиторий: **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**. Нажмите **Save**.
3. Через минуту-две сайт откроется по адресу `https://ИМЯ-АККАУНТА.github.io/unatom/`.

Сайт будет открываться у всех без входа и регистрации.
